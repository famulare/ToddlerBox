# Math launcher icon

Original ToddlerBox artwork generated with OpenAI image generation on 2026-10-04,
using the existing Music icon as the style reference. The toy abacus follows the
original glossy illustrated icon family. Transparency outside the rounded tile
and the full generated source resolution are retained. Included under the project
license; existing icons remain byte-for-byte unchanged.

The countable vocabulary drawings have their own provenance and licenses under
`assets/reading/`; the Math activity references those existing assets.
