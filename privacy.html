ToddlerBox

Privacy and Google access

Updated October 3, 2026. This describes ToddlerBox’s optional, parent-controlled Google Drive sync feature, currently being prepared for release.

Purpose and permissions

The helper uses Google Drive to download pictures selected by a parent and back up saved Paint and Typing work. It requests drive.readonly and drive.file. The read permission can see and download files across the authorized Google account; the helper confines its operations to the configured ToddlerBox folder. The write permission applies to files created or explicitly authorized for this OAuth application.

A parent creates their own Google OAuth desktop client and explicitly approves access to their account. ToddlerBox is a personal tool, not a hosted service that receives the parent’s Google authorization.

Storage and transfers

Pictures and saved work remain ordinary files on the device and in the parent’s own Google Drive. Sync uploads current and archived creations and preserves earlier cloud versions before replacing them. A separate initial backup preserves the original photo deposit. Typing backups include JSON and readable UTF-8 text.

Each transfer is requested by a parent. Sync does not run on a schedule, at boot, or when Wi-Fi reconnects. Thumbnail caches, runtime logs, and temporary files are excluded from cloud backups. Google processes transferred files under the account holder’s agreement with Google.

Credentials and access

OAuth client configuration and tokens are stored privately on the parent’s preparation computer and in protected system-owned storage on the laptop. The child account cannot read the laptop’s sync credentials. Private setup media can contain credentials and photos; the parent should remove temporary credential copies after successful setup.

The public software repository and build images do not contain family data or real Google credentials. Cloud software builds and tests use synthetic fixtures.

Retention and control

Routine sync does not propagate deletions or automatically prune backups and history. Retained files remain until the parent deliberately removes them. A parent can disconnect the helper by revoking its Google access, reconnect when needed, and recover data through ordinary files. Revoking access does not delete existing local or cloud files. Removing the software also does not by itself remove Google Drive backups.

Other uses

The sync helper does not use Google user data for advertising, analytics, sale, or AI model training. It does not transmit those files to the software developer. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

This documentation website is hosted by GitHub Pages. GitHub may process ordinary website access records under its privacy statement. The site has no application analytics, tracking scripts, forms, or family data.

Questions about the software can be raised through the public project issue tracker. Do not post credentials or private family files there.
