# 0.5.3 Paint development

Branch: dev/0.5.3-paint. This is a development candidate, not a published release.

Scope: Paint alone now caches the static control panel and cancels gestures only
on actual focus loss/backgrounding, noisy-key reset or the existing long-frame
recovery. It retains the shared pointer ownership filter, every accepted motion
sample, brush geometry, 60 Hz pacing, compositor, data paths and save lifecycle.
Home is drawn after the canvas, preserving its original placement. Selection and
recall-thumbnail changes invalidate the cache; it is private to each Paint scene.

The old code deterministically cancels a held finger after focus-gained, restored
or size events. Three new tests fail on unchanged 0.5.2 and pass with this change.
This establishes a possible stopped-stroke mechanism, not the cause of any
specific physical incident. Actual focus loss still discards queued pointer work.

Commands (synthetic data only):

```sh
uv sync --frozen --group dev
uv run --frozen pytest
SDL_VIDEODRIVER=dummy uv run --frozen python scripts/check-paint-frame-baseline.py /path/to/0.5.2/src/toddlerbox/paint/app.py
```

108 full-frame comparisons match exactly across 1024x600, 1366x768 and 1920x1080,
including selection changes, changed thumbnails, canvas changes and recall. The
brush functions are unchanged. At 1366x768 the synthetic dummy-backend median
render fell from 1.412 ms to 0.975 ms; p99 from 2.158 ms to 1.461 ms. At 1024x600
median fell from 1.048 to 0.541 ms; at 1920x1080 from 2.402 to 1.916 ms. These are
CPU rendering observations, excluding real Wayland/display/input latency.

Do not replace a signed 0.5.2 release directory or publish this candidate under
its tag. Local development installation must use a separate versioned app and
the resident updater's pending-candidate/rollback journal. Explicit local recovery
authorization does not establish signed-release qualification or physical acceptance.
The normal system/build-app.sh remains the production Ubuntu builder. A host-built
Ubuntu 24.04/Python 3.12 local experiment must be labelled as such, with commands
and hashes recorded, and must not become a production release without qualification.

After a local candidate is installed, test real continuous finger drawing,
Home/Recall saves and independent parent escape before explicit acceptance.
Rollback restores the accepted 0.5.2 pair; never roll back child data.
