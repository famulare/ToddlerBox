# ToddlerBox 0.4.0

Six offline activities in a two-row launcher: Paint, Photos, Music, Typing,
Reading and Math.

- Math joins the installer after Mac user testing: Numbers shows objects first;
  a tap reveals the numeral. Addition and subtraction use grouped tens, include
  crossing tens and stay within 0–100. No scoring or active object tapping.
  Speech plays only when deliberately requested; arithmetic reads the complete
  equation, such as "eight minus three equals five".
- Music grows from six to eighteen short public-domain melodies. The left menu
  scrolls by wheel or swipe; Free Play, Pause and Autoplay stay reachable.
  A browse swipe never accidentally starts a song. Piano keys remain playable
  alongside songs. Original recordings and illustrated icons are preserved.

Use `toddlerbox-installer.iso` for a clean Ubuntu 24.04 x86-64 UEFI installation
with Secure Boot disabled. The automatic download helper linked in
[the build guide](https://github.com/famulare/ToddlerBox/blob/main/docs/builds/README.md)
checks the complete download without GitHub login or manual hash comparison.
Etcher validates the USB write. A human must confirm the exact installation disk.

**Back up Rosie's current work privately before reinstalling.** Reinstallation
is destructive. Preserve photos, drawings, typing, configuration and private
Drive/device state on another computer before flashing the backup's USB.
See [the backup checklist](https://github.com/famulare/ToddlerBox/blob/main/docs/reinstall.md).

Existing 0.3 appliances can instead use the authenticated parent maintenance
menu's signed GitHub update path. Candidate acceptance requires a supervised
child test followed by explicit parent confirmation; child data is preserved.
Existing configuration is preserved. Exact historical standard five-app profiles
display all six icons automatically; custom launchers retain their choices and
can add the Math entry from the repository config. A fresh install includes it.
Maintenance and Drive sync remain parent initiated.

The release includes exact source/checksum/package records and VM qualification
results. Fresh installation and recovery are tested in a no-network x86-64 VM;
that evidence does not validate the HP's physical Wi-Fi, gestures, trackpad,
speaker loudness or sleep/resume. Those remain hardware acceptance checks.
Private family media, Google credentials and signing keys are absent from all
public source and release artifacts.
