# ToddlerBox 0.5.1 — responsive input and Music

A signed application update for an existing Ubuntu 24.04 x86-64 ToddlerBox
appliance. No OS reinstall, Git checkout or credentials are needed. Existing
configuration, drawings, documents and private Drive state are preserved.

- Reading opens in picture view. Reading and Photos prepare bounded previews
  ahead of scrolling without decoding files during rendering.
- Math Next accepts modest finger drift and uses the whole button plus a small
  safe margin. There is no pressure threshold or visual change.
- Piano keys sustain while held and decay for 600 ms after release. All keys
  prepare silently before input. Songs are louder; Reading/Math audio stays as
  before. Existing app gains and startup volume are preserved.
- Paint fill searches whole exact-color runs, including opaque restored PNGs.
  Fountain drawing avoids redundant work while keeping the same stroke pixels.
- Paint/Typing keep rendering during durable New/Recall/Home saves. Old work is
  archived successfully before clearing; repeated actions are gated while pending.
- A deliberate [parent speaker check](../parent-maintenance.md#parent-speaker-check)
  uses the already-installed PipeWire player. No extra apt install is needed.

## Install through the normal updater

Enter parent mode with Ctrl+Alt+Home and save parent desktop work. Open
**ToddlerBox Setup & Maintenance**, choose **Check updates**, then **Install
update**. Return to the child session and test the candidate. Enter parent mode
again and choose **Accept tested update**. The signature and download checks are
automatic. Until acceptance, the previous working system/app pair remains the
recovery target; rollback preserves child work.

On the HP, check picture-list finger scrolling, fountain strokes and bucket fill,
New/Recall/Home in Paint and Typing, Math Next, sustained piano notes and songs,
then parent escape. VM input cannot establish physical touch latency or speaker
balance. Keep custom volume settings unless you deliberately choose the louder
0.5.0 defaults; this patch does not reset them.

## Scope

This is update-only: the existing qualified installer remains available separately.
ALSA/PulseAudio diagnostic utilities are added to the future-image recipe, not
installed by this bundle. Wi-Fi/DNS, USB setup, root recovery and credentials
retain their existing configuration and trust boundaries. See
[updates](../updates.md), [parent maintenance](../parent-maintenance.md) and
[validation](../../VALIDATION.md) for recovery and test evidence.
