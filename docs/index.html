ToddlerBox

Version 0.3.0 includes five offline activities, authenticated parent setup and signed public updates. Ordinary child use needs no internet connection.

ToddlerBox turns a Linux laptop into a simple, fullscreen place for a young child to paint, type, explore photos, make music, and read.

Private Google Drive sync

The optional sync feature is included in the new ToddlerBox installer. A parent explicitly requests each transfer. It downloads parent-managed pictures and uploads the child’s saved Paint and Typing files to a private folder in the parent’s Google Drive.

There are no scheduled transfers. Data stays in ordinary files on the laptop and in the parent’s own Google account. The public source repository is separate from family photos, creations, and credentials.
